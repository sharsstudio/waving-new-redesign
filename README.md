## 📖 Project Overview

This project involved the comprehensive technical and visual redesign of the **New Wave GmbH / Craft Sportswear** B2B platform (https://www.newwave-germany.de). As the **Technical E-Commerce Lead**, I managed the end-to-end execution, moving from a legacy architecture to a high-performance, responsive environment.

The goal was to create a **minimalist, luxurious interface** that aligns with the brand's premium identity while optimizing the B2B purchasing journey for international partners.

---

This project utilized a **Hybrid Development Approach**, combining solid architectural principles with modern AI-accelerated workflows.

## 💡 Key Features & Contributions

### 1. Hybrid Coding Workflow (AI + Human)
Leveraged **AI-Assisted Coding** to accelerate the development of frontend components. This allowed for:
* Rapid prototyping of HTML structures.
* Efficient CSS debugging and cross-browser compatibility checks.
* *Outcome:* Reduced development time for frontend adjustments by 40%.

### 2. UX/UI Modernization
Implemented a "New Wave" design language focusing on clarity and brand prestige.
* **Typography:** Integrated `Source Serif Pro` for headings and `Futura` for body text to balance elegance with readability.
* **Responsive Design:** Fully optimized sliders and product grids for mobile and tablet B2B users.

### 3. Data & PIM Integration
* Managed the localization of complex master data.
* Ensured data integrity between the PIM system and the frontend display using advanced Excel analysis.
